# Kamisei AI Assistant (WordPress plugin)

施工事例をもとにお客様の要望をヒアリングし、近い事例を提案、希望があれば担当者へ引き継ぐAIチャットです。

## インストール
1. `kamisei-ai-assistant.zip` を WordPress 管理画面の「プラグイン → 新規追加 → プラグインのアップロード」で入れて有効化します。
2. 「設定 → AIアシスタント」で次を設定します。
   - Anthropic APIキー(`wp-config.php` に `define( 'KAIA_API_KEY', '...' );` でも可・推奨)
   - 施工事例の投稿タイプと、(投稿内にある場合は)事例のカテゴリー、補足で紹介する参考記事のカテゴリー
   - 通知先メール、電話番号、予約ページURL、プライバシーポリシーURL
3. サイトを開くと右下にチャットが表示されます。

## 2つのモード
- **検索のみ(APIキー未設定・無料)**: 検索ボタン/キーワード入力で施工事例・参考記事をカード表示し、問い合わせフォームで担当者へメール通知します。
- **AIチャット(APIキー設定済み)**: 下記のとおり会話で要望を聞き、事例を提案します。

キーを入れると自動でAIチャットに切り替わります。

## 動作(AIチャット)
- ブラウザからは自サイトの `/wp-json/kaia/v1/chat` だけを呼びます。APIキーはサーバー側にのみ存在します。
- AIは `search_cases` で施工事例を探しカード表示します。あわせて `search_articles` で、参考記事カテゴリー(リフォーム解説・お客様の声など)から補足記事を1〜2件紹介します。カテゴリーが未設定だと何も紹介しません。
- お客様の同意・名前・連絡先が揃うと `request_handoff` で問い合わせを保存(管理画面「AIチャットの問い合わせ」)し、メール通知します。
- IPごとに1時間あたりの回数制限があります(既定20回)。

## 既知の制限(v0.1)
- 事例検索はタイトル・本文・カテゴリー名・タグ名が対象です。ACFなどのカスタムフィールドは対象外です。
- 実際のWordPress上ではまだ動作確認していません。ステージング環境での確認を推奨します。
